PRISM app design spec

How the Meta Quest app should look after the redesign: deep navy panels taken from the logo, one mint accent, and charts where only the answer stands out. Every value here can be set in Unity without new features. A phone version of the app follows the same system.

For the Unity build · Version 1 · November 2026

Audit

What changes

Frames from the current build. Each one shows the pattern the redesign replaces.

Brand

Logo

The original PRISM logo, rebuilt as clean vectors: faceted triangles in blue, violet, pink and teal, with PRISM set in League Spartan SemiBold and outlined. Use the full logo on its navy background, the compact version where the logo sits small, and the mark alone for icons. Files are in the website repo under public/brand/.

Use

  • Full logo on navy for the splash screen, covers and slides
  • Compact logo in navigation, footers and anywhere it sits small
  • Mark alone on navy for the app icon and favicon
  • Clear space around the logo of at least the small pyramid's height

Avoid

  • Changing the triangle colors or gradients
  • Stretching, rotating or rearranging the triangles
  • Setting PRISM in another font
  • Busy photos or mid-tone backgrounds behind the logo

App icon and splash

Both use the logo navy, a vertical gradient from #0B0056 to #060039. Where only one color is allowed, use #0A0050. Files are in public/brand/app/.

Tokens

Color

Panels use the navy from the logo, so the app, its icon and the website footer feel like one product. Text stays light and quiet. The accent is the logo's mint, and it appears once per view, on the thing that answers the question.

Tokens

Type and spacing

Geist for all text and Geist Mono for figures and meta, both free under the OFL. Import them as TextMeshPro SDF font assets. Sizes assume a world-space canvas at scale 0.001, so 1 canvas unit is 1 mm, with panels placed 0.9 to 1.1 m from the user.

Spacing

4 mm grid. Panel padding 24, gap between groups 16, inside a group 8.

Radius

Panel 20, answer card 14, buttons and controls 10.

Weights

Regular and Medium only. No bold, italic or all caps.

Panel widths

Conversation 480, chart 640, record control 260.

Components

3D chart

The 3D graph is the one rich element in the app. Keep it physical and quiet: matte navy bars on a floor plate, small labels, and the mint accent on the answer.

Operations by typePinch a bar for details

Materials

  • URP Lit, metallic 0, smoothness 0.2
  • No emission and no bloom on bars
  • Neutral bars #3D3894, highlighted bar #63D2B4
  • Floor plate #140F66 with a hairline edge

Labels

  • Geist Mono 18, billboarded to face the user
  • Value 20 mm above the bar top, name at the base
  • One line each, never larger than the bar width
  • On pinch, a small card: Lathe · 212 operations
Phone

PRISM on phones

The same assistant for people who are not wearing a headset. Ask by voice or by typing, read the answer and chart on the phone, then place the 3D chart on a table or the floor in AR. It uses the same colors, type and source line as the headset, so a team can move between the two.

Try it

  1. Tap a recent question, or press the button to ask by voice
  2. The answer arrives the same way as on the headset: question, analyzing, then the figure and chart
  3. Tap View in AR, then tap a bar to see its detail sheet

One thumb

The hold-to-ask button sits at the bottom center, 64 pt. Every other tap target is at least 44 pt.

Voice or text

A text field under the button for loud floors and quiet offices. Follow-ups keep the same dataset.

Feedback

A light haptic when listening starts and stops. The status line reads Listening, then Analyzing with the file name.

AR placement

Place the chart on a detected surface. Tap a bar for a detail sheet. Move and Reset sit in the sheet, not over the camera.

Build notes

  • Navy theme by default to match the headset and the app icon; follow the system Dynamic Type and text-size settings
  • The phone app can talk to the same local PRISM server, so raw data still never leaves the network
  • If the headset app stays in Unity, AR Foundation can reuse the same 3D chart on iOS and Android
  • Recent questions live on the device; clear them from a settings screen

Motion

Panels appear

Fade in and rise 8 mm over 300 ms.

Button press

Scale to 0.97 over 120 ms.

3D bars

Grow from the floor over 400 ms, 50 ms apart.

Easing

cubic-bezier(0.22, 1, 0.36, 1) everywhere. No looping glow or pulse.

Build

Unity checklist

  • Import Geist and Geist Mono and create TextMeshPro SDF assets; set Geist as the default TMP font
  • Replace the purple panel material with the Panel color at 94% alpha and a 1 px hairline border
  • Remove gradients from chart bars; color every bar Chart neutral and the answer's bar Accent
  • Swap pie charts for the stacked bar and legend, or a donut when a pie is requested
  • Turn off emission and bloom on 3D bars and cap 3D label size at Geist Mono 18
  • Shorten the assistant prompt so answers lead with the figure and end with the source file name
  • Update the app icon and splash with the new mark
  • Check every text size on a Quest headset at 1 m before release
